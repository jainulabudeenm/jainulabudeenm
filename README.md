## Hey, I'm Zain

Product designer. I build agent tooling for Claude Code, mostly skills that encode a way of
thinking rather than a feature.

### Skills you can install

| Skill | What it does | Install |
|---|---|---|
| [cart-cop](https://github.com/jainulabudeenm/cart-cop) | Makes you defend a purchase before it approves one | `/plugin marketplace add jainulabudeenm/cart-cop` |
| [company-recon](https://github.com/jainulabudeenm/company-recon) | Investigates a company before you interview, from employee chatter rather than PR | `/plugin marketplace add jainulabudeenm/company-recon` |
| [mobile-screen-eval](https://github.com/jainulabudeenm/mobile-screen-eval) | Audits a mobile screen against Nielsen's 10 heuristics, WCAG 2.1 AA, and iOS HIG plus Material guidelines | `/plugin marketplace add jainulabudeenm/mobile-screen-eval` |
| [name-cop](https://github.com/jainulabudeenm/name-cop) | Kills your weak name candidates instead of ranking them, using Alexandra Watkins' SMILE and SCRATCH frameworks | `/plugin marketplace add jainulabudeenm/name-cop` |
